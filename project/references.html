References

This page lists all external resources used in the creation of this website.

Images

  • Hero Image (Arequipa cityscape): Sourced from Picsum Photos (random placeholder image service).
  • Member Profile Images (Minera, Tecnología, Textiles, etc.): Placeholder images generated using Picsum Photos with custom seeds (e.g., https://picsum.photos/seed/minera/200/150).

Icons & Fonts

  • Social Media Icons (Instagram, Facebook, TikTok): SVG icons provided by Simple Icons via CDN (https://cdn.simpleicons.org/...).
  • Typography (Playfair Display & Nunito): Fonts imported from Google Fonts (https://fonts.googleapis.com/css2?family=Playfair+Display...).
  • Favicon: Inline SVG emoji (🏛️) used as a placeholder icon.

Content

  • Business Descriptions: All text describing the member businesses (Minera Los Andes, Textiles Arequipa, etc.) is original content created specifically for this project.
  • Website Concept: The Arequipa Chamber of Commerce is a fictional organization created for educational purposes (WDD 131 - Final Project).
